# Security Policy

## Reporting a vulnerability

Please report vulnerabilities through GitHub's private vulnerability reporting
feature on this repository. Do not include exploit details, credentials, or
personal information in a public issue.

Include the affected file or URL, expected impact, and minimal reproduction
steps. Reports will be reviewed as availability permits.

## Third-party repositories

Underground GitHub links to projects maintained by other people. Inclusion is
not a security endorsement. Do not run downloaded software without reviewing
its source and release provenance.
